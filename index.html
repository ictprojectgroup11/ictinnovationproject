How It Works & The Function Code

form.addEventListener('submit', (e) => {
    e.preventDefault();
    const name = nameInput.value.trim();
    const qty = parseInt(qtyInput.value) || 1;
    
    if (name) {
        shoppingList.push({
            id: generateId(),
            name,
            quantity: qty,
            purchased: false
        });
        
        nameInput.value = '';
        qtyInput.value = '1';
        renderUI(searchInput.value);
    }
});
1

FUNCTION

The form submit event listener intercepts the form submission to add new items securely to the shopping list array.

2

PARAMETERS

It sanitizes inputs from the DOM, defaulting to a quantity of 1 if invalid, and verifies the name isn't empty.

3

DATA PERSISTENCE

A new object is generated with a unique ID and then pushed to the array. renderUI() handles saving to Local Storage and updating the DOM.
